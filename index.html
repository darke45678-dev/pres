  • 跨平台通用性：轉換為標準 ONNX 格式，擺脫 Python 與 PyTorch 依賴。
  • 頻寬友善：13MB 極小體積，4G/5G 行動端 1~2 秒內即可完成快取下載。
ONNX Runtime Web 邊緣推論優勢

利用瀏覽器 WebGL 與 WebAssembly 調用本機 GPU/CPU 平行運算，無需回傳雲端伺服器，保護隱私並達成 0 元營運成本。

前端工程落地與互動細節

非同步預載入 (Async Preload)

首頁背景靜默加載 ONNX Session，相機開啟時推論已 Ready，首屏零卡頓。

動態信心度滑桿 (Confidence Slider)

提供即時門檻調整（預設 0.45），光線不佳下可動態過濾背景雜訊與誤觸。

200% RWD 縮放抗變形與 iOS Safari 優化

Canvas 與相機流完美座標映射，解決 iOS 滿版位移，達成穩定 60 幀互動體驗。
