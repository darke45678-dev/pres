## 📊 專案技術亮點

* **零伺服器成本 (0 Server Cost)**：YOLO 模型轉 ONNX FP16 半精度量化（26MB $\rightarrow$ 13MB，瘦身 50%），利用 WebGL 在瀏覽器純本地 45ms 極速推論。
* **5,560 張真實照片與三階資料劃分**：87% 訓練集、9% 驗證集、4% 盲測測試集。
* **多維影像增強提升泛化能力**：導入 Mosaic（抗遮擋）、Mixup（抗反光與霧氣）、HSV 抖動（抗黃白燈光與手影）。
* **定位懲罰調優**：調高 Box Loss 懲罰（$\lambda_{box} = 7.5$），精準鎖定食材發黑發霉邊緣，達成 86.8% mAP@50 與腐壞肉類 100% 滿分辨識率。
* **前端體驗優化**：手勢操作鎖防誤觸、200% RWD 彈性排版、iOS 60 FPS 順暢算圖。
